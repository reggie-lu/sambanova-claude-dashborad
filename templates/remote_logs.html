Use SSH to bring the recorded requests, tokens and timing to this computer. Works with both setups above and ordinary Claude sessions.

VM logs→SSH copy→Cost LensOne imported source at a time · no dashboard port exposed

You need SSH access, Python 3.10+ on the VM, and rsync on both machines. Run the commands below in the same local terminal, from your Cost Lens repository. Replace user@your-vm with your SSH destination.

  1. 01 · ONE-TIME PREPARATION

    Capture the provider on the VM

    Copy the small helpers and install the endpoint hook on that machine. Start or restart Claude Code there afterward, using your usual model settings.

    The hook records the endpoint, never the API key. Existing logs still work; requests recorded before the hook may rely on model-name inference.

    Local terminal → VM

  2. 02 · AFTER YOUR TASK

    Export, then bring the logs home

    The exporter keeps the session and subagent folders intact. The copy goes into data/imports/my-vm/, separate from your local sessions.

    For coding offload, first expand the optional instructions below to include the tracked runs and their detailed logs.

    Local terminal → VM → local folder

  3. 03 · VIEW IN YOUR BROWSER

    Point Cost Lens at the copy

    Stop the current dashboard with Ctrl+C in its server terminal, then run this command from your local repository. Open 127.0.0.1:5055.

    This selects the VM archive for all totals and sessions. Your local logs stay in place. To return to them, stop this server and start it normally without COST_LENS_LOG_DIR.

    Local terminal · existing Cost Lens environment

Optional · local terminal → VM

Missing detail files preserve the recorded run total, but cannot reconstruct individual requests. Check the exporter’s warnings. If no tracker recorded SambaNova usage, copying Claude logs alone cannot recover those tokens.

Need a newer view?

Repeat step 02 with the same export options. Cost Lens checks the copied files every 5 seconds; it does not contact the VM. The source label shows the export time. Repeated exports retain archived transcripts, and unfinished runs show only their observed timing.

Only transcripts, endpoint history and selected offload logs are copied—not credentials or Claude settings. Transcripts can contain prompts, code and tool output. Use a separate import folder for each VM.
